# Portfólio Backend - Pablo Martins

Portfólio focado em primeira oportunidade como desenvolvedor backend.

O site destaca apenas os projetos mais fortes: controle de ponto, sistema de gestão e API de notas fiscais. A ideia é mostrar capacidade real com Node.js, TypeScript, APIs REST, autenticação, banco de dados, Docker, HTTPie, Render e Neon, mantendo React como apoio para dashboards e interfaces.

## Projetos em destaque

- **Martir Ponto Digital**: produto completo com API, dashboard web, app mobile, geolocalização, autenticação e relatórios.
- **IgrejaGestTec**: gestão financeira e espiritual para igrejas com perfis, relatórios, PostgreSQL, Prisma, Render e Neon.
- **API de NFS-e**: API SaaS multiempresa para notas fiscais de serviço, XML, certificado A1, auditoria e testes HTTP.

## Rodando com npm

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: inicia o projeto em modo de desenvolvimento
- `npm run build`: gera a versão de produção
- `npm run lint`: executa o ESLint
- `npm run format`: formata os arquivos com Prettier
